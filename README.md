# Amandus Procurement Group website

An Astro site with React components.

## Work locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Astro writes the static site to `dist/`.

## Deploy on Vercel

Connect this private repository to Vercel and import it as a new project. Vercel can detect Astro and use `npm run build` with `dist` as the output directory. Pushes to the production branch update the live site; other branches can provide preview links.

Before sharing the site, open the Vercel project's **Security → Deployment Protection** settings. Set **Vercel Authentication** to **All Deployments** so the production URL and preview URLs require access. Then grant individual reviewers access or create a shareable link, depending on how you want to share the preview.
