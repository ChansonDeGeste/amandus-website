# Amandus Procurement Group website

An Astro site with React components.

## Work locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Astro writes the static site to `dist/`.

## Deploy on Vercel

Connect this private repository to Vercel and import it as a new project. Vercel can detect Astro and use `npm run build` with `dist` as the output directory. Pushes to the production branch update the live site; other branches can provide preview links.

Keep the GitHub repository private. The Vercel production URL is intended to be public so it can be shared with visitors. If you want draft branch previews restricted, use **Standard Protection** under the Vercel project's **Security → Deployment Protection** settings; this leaves the production URL public.
